# Proyecto Angular

Proyecto base creado con Angular.

## Comandos

```bash
npm install
npm start
```

La aplicacion quedara disponible normalmente en `http://localhost:4200/`.

## Despliegue seguro

La configuracion Docker para publicar el frontend y la API con HTTPS esta en [deploy/README.md](deploy/README.md). Requiere un dominio apuntando al servidor, Docker Compose, un `.env` local y un secreto JWT fuera de Git.
